# מיני דף נחיתה — ממתחיל למקצוען בבינה מלאכותית

דף נחיתה למיני-קורס של **נעם AI**.

**חי:** https://noam-gever.github.io/noam-ai-mini/

## מבנה
- `index.html` — הדף עצמו (קובץ אחד, בלי תלויות חוץ מגוגל-פונטס)
- `תקנון.html` · `פרטיות.html` · `נגישות.html` — מסמכים משפטיים
- `assets/` — לוגו

## שים לב
- הכפתורים מובילים ל-`#` — צריך להחליף בקישור לדף התשלום
- המסמכים המשפטיים הם **טיוטות שלא עברו עורך דין**
